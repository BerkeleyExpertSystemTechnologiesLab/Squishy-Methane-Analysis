## Outcome

The large displaced source posterior from the original synthetic history does
not persist at the same magnitude when observations are generated by the
estimator's own discrete model. Residual posterior-mean displacement remains;
this does not establish unbiased estimation or calibrated source uncertainty.

Source error is Euclidean distance in normalized (y,x) FOV coordinates, not meters.
Final model-consistent source summaries use a 257x257 quadrature. Original-history
reference numbers are from the previous 129x129 run, whose J refinement passed
but whose full source posterior convergence was not established.

| Accurate region | .062845 | .002518 | .006715 | .002604–.009362 |

| Accurate point | 0, prescribed | 0, prescribed | 0, prescribed | 0 |
| Biased point | .205913, prescribed | .205913, prescribed | .205913, prescribed | .205913 |

All three distribution priors put the true position inside their approximate 95%
highest-posterior-density set in all ten stochastic runs. The mean-control case
also includes truth for all three priors. Posterior mass within .05 FOV is
numerically approximately one. These counts describe ten samples at one fixed
source and path; they are not prior-predictive calibration, independent pixel
coverage tests, or evidence of general localization performance.

The source posterior means still have directionality across these seeds:

| Prior | Mean displacement (y,x) | Monte Carlo standard error (y,x) |
|---|---|---|
| Broad | (-.003538, +.003988) | (.001150, .001112) |
| Accurate region | (-.003491, +.003956) | (.001140, .001103) |
| Biased region | (-.004481, +.005403) | (.001243, .001118) |

Thus "the bias disappeared" would overstate the result. Even without realized
noise, the posterior mean is not exactly at truth. The mean-control exact true
source has higher likelihood than every evaluated source-grid node. A posterior
mean need not equal a likelihood maximizer, especially under a nonlinear
source-position-to-input map. The remaining effects of posterior shape, prior,
finite data and discretization have not been separately isolated here.

## What changed and what remained fixed

Both controls reuse the historical 40 s schedule, all 708 positions, footprints,
acquisition times, 0.0125 s delivery delays, wind, source location/rate/width,
12x16 latent grid and decay. All five priors receive the same observations within
each realization; source parameters other than location are fixed/known.
No new policy decisions are generated. The original path came from a known-source
policy, so this is a conditional inference diagnostic, not a discovery benchmark.

`MatchedFieldGenerator` advances an unconditioned latent field with the same
advection, diffusion, decay, injection and observation operator as the estimator.
It uses independent stencil code and never adjusts truth using measurements.

- Matched mean: initial mean and zero realized process/measurement perturbations.
  Inference still uses its original assumed P0, Q and R; this is not a random draw
  from the probabilistic model or a calibration run.
- Stochastic: ten preregistered seeds 20261028–20261037 draw the initial correlated
  field, all process increments and measurement noise from the assumed model.

Gaussian states may be negative: no clipping is applied. This is a statistical
control, not a physical methane simulator. The model treats an observation as a
footprint-weighted scalar at acquisition time; recorded integration duration is
not additionally simulated as a temporal average. Existing peak-amplitude source
injection and its grid/boundary dependence remain unchanged.

## Field and predictive diagnostics

The full direct-filter runs save per-reading prediction/RMSE/log likelihood,
interval coverage, post-assimilation acquisition-time field MSE and final field
coverage. These secondary metrics are at the 129 source grid; the subsequent
257 refinement changes only final source quadrature summaries. Event-averaged
field MSE is NOT the previous physical-time-integrated J/T.

At order 129, stochastic mean observation coverage is 94.32%, 94.52%, 94.27%,
94.38%, 84.35% for broad, accurate region, biased region, accurate point, biased
point respectively. Final marginal field coverage averages 96.04% for the three
mixtures, 95.57% for accurate point and 76.30% for biased point. The known-source
mean control gives reading RMSE 1.13e-16 and post-reading field MSE 1.63e-32,
confirming deterministic forward/filter consistency. No coverage guarantee is
inferred from these correlated, fixed-geometry measurements.

## Interpretation and next discriminator

The experiment supports model mismatch as a substantial contributor to the
original large displacement: keeping location, priors and acquisition schedule
fixed while replacing the original synthetic field with the estimator's own
forward model sharply reduces source-location error. It does not isolate which
original discrepancy (transport, field representation, source input or observation
model) was responsible, nor prove that source inference is unbiased.

The next useful experiment is to introduce one controlled mismatch at a time
(e.g. source width, wind, lifetime or the original observation operator), while
retaining common random realizations and the fixed path. Increasing independent
sources/geometries and validating posterior uncertainty are still needed before
using these results as a paper-level calibration or robustness claim.
