# Model-consistent fixed-path source-prior control v1

Question: does the sharply displaced source posterior from the original synthetic
history persist when truth is generated by the estimator's own discrete model?
This is an evaluator-only diagnostic; production inference and scan policies do
not change. Starting branch `codex/source-prior-fixed-evidence`, HEAD
`5cac633f47001d3aa455f8b6f3cc00b11c550ed3`, with the preceding study's uncommitted
changes preserved. See `configs/source-prior-study/model-consistent-v1.json`.

## Frozen design

Keep the original source location, rate, width, 12x16 latent grid, transport,
diffusion, decay, wind, all 708 positions/footprints, acquisition and delivery
times, scan boundaries and 40 s horizon. Replay the path as an exogenous schedule;
do not ask the policy to reproduce its original decisions on changed readings.
The original scan path was selected with source knowledge and is not a neutral
source-discovery design. Reading delivery remains 0.0125 s after acquisition.

Generate an unconditioned state using the same substep boundaries as inference:

    x_0 ~ N(m_0, P_0)
    x_(k+1) = F_k x_k + b_k(source) + eta_k
    eta_k ~ N(0, Q_k)
    y_j = gain * H_j x_(acquisition_j) + offset + epsilon_j
    epsilon_j ~ N(0, sensor_noise_std^2)

F includes original advection, absorbing-boundary diffusion and decay; b is the
original point-sampled source injection. Q uses the original kernel and exact
decay-scaled process variance. P0 includes the original 1e-12 diagonal jitter.
The generator uses an independently implemented stencil path, not the source
bank's sparse transport function. It never conditions truth on readings.
No positivity clipping: signed Gaussian states are required for this statistical
control and are not a realistic methane simulator. The observation operator is
the estimator's footprint-weighted scalar at acquisition time; the recorded
integration duration is preserved metadata, not an added temporal convolution.

Two controls, fixed before execution:

1. `matched_mean`: initial mean, zero realized process and measurement perturbation;
   inference retains its original assumed covariances. A deterministic forward
   consistency control, not a random sample calibration experiment.
2. Seeds 20261028 through 20261037: full independent P0, Q, R sampling. Source,
   path and nuisance parameters remain fixed. All five methods use exactly the
   same generated evidence within a seed. No seed selection after observing results.

Retain the five source priors from the prior study, including oracle-informed
accurate conditions. Regions retain soft support across the entire FOV.
All other parameters remain known. No activity/strength/wind inference.

## Scores and numerical checks

Primary: final source posterior mean/error/displacement, mass within .05 FOV of
the true location, effective sample size, and membership of the true location in
a 95% highest-density set. For continuous source priors, evaluate the likelihood
at the exact off-grid truth using the extra exact-location component, compare
prior-times-likelihood density with grid densities, and integrate mass above the
truth density. Rank <= .95 denotes membership. This is a quadrature estimate,
not a Gaussian ellipse or a nearest-cell test. A point prior has prescribed,
not inferred, source location; its membership is trivial.

Secondary: pre-assimilation predictive log score/RMSE/interval coverage; mean
post-assimilation acquisition-time latent-field MSE over 708 observations; final
latent-field MSE and exact-mixture marginal interval coverage. The event average
is not a time integral and must not be labeled J/T or compared numerically with
the preceding J/T. No later reading improves an earlier score. Acquisition-time
scores are reported after delivery and do not claim real-time zero latency.

Run 65 and 129 source quadrature orders on every control. Require source posterior
mean shift < .002 FOV, absolute change in .05-radius mass < .02, and unchanged
95% HPD membership. Preserve failed results and add a separately configured finer
comparison if needed. These checks validate the declared summaries, not full
posterior density convergence or uncertainty calibration. Ten fixed-location
seeds provide descriptive diagnostics, not prior-predictive simulation-based
calibration or a general localization benchmark.

Verify generator deterministic means against the original DecayGaussianBelief,
Monte Carlo covariance against its independent propagation, measurement noise,
seed reproducibility, and exact-point filtering against the original filter at
every event. Save configuration, source code, environment, original evidence,
generated scalar evidence, latent truth, traces, source posteriors, figures and
SHA-256 manifests. Original evidence must remain unchanged.
