# Source-assumption experiments

## Problem

If our assumptions about the methane source are wrong, how does that affect our
interpretation of the measurements?

These experiments test the reconstruction step: hold a sequence of scalar
measurements and its scan path fixed, then compare the maps inferred under
different source-location assumptions. Follow-up controls test model mismatch.

The baseline is the reference implementation for these controlled comparisons.
Its reconstruction results are mixed and its field uncertainty is not calibrated.
The original simulator and field estimator use different representations; the
model-consistent control is a separate statistical test, not the original plume
simulator or a physical methane-flow model.

The source-assumption tools do not change production scan-policy behavior. The
reference path was originally selected using known source information. Replaying
that path isolates inference differences but does not evaluate unknown-source
search or the effect of new maps on future scan decisions.

| Item | Current experiment | Physical integration still required |
| --- | --- | --- |

The synthetic gain is 1 and offset is 0. The code does not convert raw hardware
voltage into calibrated gas concentration or emission rate. There are no real
camera clips or external datasets in this quickstart. Simulator truth is used by
the evaluator and visualization; accurate source hints are explicitly constructed
oracle controls, not outputs from a source-identification module.

### Reference timing and signal settings

The reference profile is `synthetic_coarse_20hz_v1`: 20 Hz nominal acquisition,
0.025 s integration, zero additional configured delivery delay and zero settling
time. Streaming readings become available at exposure completion; acquisition
timestamps are exposure midpoints, so zero added delay does not mean zero elapsed
time between acquisition and availability. Motion speeds are 1 FOV/s vertically
and 0.625 FOV/s horizontally. These are provisional synthetic settings, not
measured camera-prototype or photodiode-instrument rates.

The existing 40 s record contains 708 readings: a 33.575 s full scan followed by
3.2 s and 3.15 s focused scans. No additional noise is added by the original
simulator, while the estimator assumes sensor-noise standard deviation 0.05.
The estimator fixes source width at 0.035 FOV and peak source rate at
0.2829738193616142. That rate controls the model's source input, not a conserved
physical methane emission total. The matched-model controls generate their own
explicitly declared process and measurement perturbations.

## How source information enters reconstruction

A **prior** is the estimate and uncertainty before a reading. A **posterior** is
the estimate and uncertainty after incorporating that reading. Source-location
uncertainty and field-map uncertainty are different quantities.

During prediction, the assumed source location places **source injection**:
new modeled signal near that position. Wind transports the field; diffusion and
decay change it over time. A scalar reading then updates the field estimate.
Consequently, an incorrect source assumption can change the map even when the
measurements are identical.

For a point assumption the source location stays fixed. `SourcePriorBank` instead
maintains a conditional Gaussian field for each candidate source location and
updates candidate weights using pre-update predictive likelihoods. Its field
uncertainty includes both within-candidate and between-candidate variation.
The five-method comparison uses broad, accurate/biased regional, and
accurate/biased point assumptions. Regional assumptions have standard deviation
0.06 FOV per axis and soft support throughout the field of view.

## Comparisons and evidence

| Comparison | What changes | What the comparison addresses |
| --- | --- | --- |
| Fixed-evidence source assumptions | Source-location distribution | Map sensitivity to incorrect or uncertain source information under identical evidence |
| Model-consistent control | Generate new observations with the estimator's own discrete model | Whether original simulator/estimator mismatch contributes to source displacement |
| One-factor mismatch | Wind speed, source width or half-life, separately | Sensitivity to each declared mismatch on the fixed path |
| Conserved-input width control | Separate width changes from changes in total discrete source input | Distinguish shape effects from signal-amount effects |

Every method shares evidence within a realization. Changing a data generator or
mismatch condition creates different observations; those cross-condition
comparisons must not be described as identical-data comparisons.

The primary original-history metric is causal time-averaged spatial squared
field error, `J/T`. In the saved 129 x 129 source-grid comparison, the accurate
point, biased point and biased region have `J/T` of 0.01656866, 0.02514605 and
0.01642077, respectively. The regional version has 34.70% lower map error than
the biased point on this one history, but its source-location estimate remains
biased. Better map error does not establish correct localization or calibrated
uncertainty. Detailed settings, numerical refinement and limitations are in the
linked study reviews below.

## Run the scanner and visual comparison

From `PlumeScanner/`, install the package and plotting dependencies:

```sh
python -m pip install -e '.[dev,plots]'
python scripts/run-scanner-demo.py --output outputs/baseline-example
python scripts/demo-source-assumptions.py \
  --record outputs/baseline-example/runs/demo.json \
  --output outputs/source-assumptions-example
```

Use the appropriate environment interpreter, such as `.venv/bin/python` or
`.venv\Scripts\python.exe`. For an uninstalled source checkout, set `PYTHONPATH=src`.
Each output destination must be new. Alternatively, running
`python scripts/demo-source-assumptions.py --output outputs/source-assumptions-fresh`
generates and replay-checks its own baseline record.

The visualization shows simulated truth, a correct fixed source hint, an offset
fixed source hint, and their identical delivered readings. It saves PNG, GIF,
numerical frames, the copied record, configuration and file hashes. MP4 is also
written when FFmpeg or optional `imageio-ffmpeg` is available. The 40 s simulation
plays in about 20 s; playback speed does not alter acquisition timing. Both hints
remain fixed, and the displayed maps omit uncertainty.

Generated evidence and media stay in ignored local output directories. The
archived study configurations reference saved local records and their hashes;
they are not bundled with a clone. The visual quickstart above generates fresh
evidence without those archives.
