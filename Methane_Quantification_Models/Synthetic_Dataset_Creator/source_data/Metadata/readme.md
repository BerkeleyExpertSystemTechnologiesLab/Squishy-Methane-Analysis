# Metadata Files

This directory contains metadata combining the original GasVid dataset information with Squishy Robotics plume modeling estimates.

## Files

- `GasVid Logging File.csv` - Original METEC facility data from the GasVid paper
- `classes.json` - Leak rates for all 8 classes in code-friendly JSON format
- `Gasvid Plume Models.csv` - Squishy Robotics PPM estimates from GasVid leak rates
- `consolidated_metadata.json` - Combined data from GasVid and Squishy Robotics for all 8 classes across all 28 videos

## Data Sources

- **GasVid Dataset**: Original data collected at the METEC facility for methane leak detection research
- **Squishy Robotics**: Cone modeling estimates for plume PPM concentrations based on GasVid leak rates
